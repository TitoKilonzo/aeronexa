# Implementation roadmap

1. Foundation: app shell, Auth, user profiles, organization membership model, RBAC and environment/deployment setup.
2. Airline catalogue: airlines, airports, aircraft, schedules, fare classes and internal inventory.
3. Booking engine: search, price snapshots, seat holds, booking state machine and concurrency tests.
4. Payments: provider abstraction, M-Pesa sandbox, hosted card checkout, webhook verification, ledger and reconciliation.
5. Ticketing: supplier adapters, reservation lifecycle, ticket issuance, cancellation and refunds.
6. Agencies: agent onboarding, customer profiles, commissions and agency reporting.
7. Airport operations: check-in, manifests, boarding, delays and cancellation operations.
8. Fleet: maintenance windows, aircraft assignment constraints and utilization.
9. Production hardening: observability, backups, load testing, security review, data retention and deployment runbooks.
